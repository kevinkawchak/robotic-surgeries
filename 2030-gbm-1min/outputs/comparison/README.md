## On-Prem LLM Backend

The script honors `ANTHROPIC_API_KEY` and `--backend ollama` for fully
on-premises execution. In this run the deterministic round logic computes
weighted-delta winners; the default model id stays `claude-opus-4-7` for the
PR record. No outbound network calls are made by the round logic in this
build; the rationale strings are templated.
