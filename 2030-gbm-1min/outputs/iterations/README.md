# 16-Iteration Sweep Outputs

Generated by `python -m simulation.iterate_1min --seed 20260510 --iterations
16 --out outputs/iterations`. Per-iteration sweep tuples linearly interpolate
sensor noise sigma (0.01 to 0.05 mm), force feedback gain (0.8 to 1.2), and
heartbeat jitter sigma (0 to 50 microseconds), and log-interpolate the IK
solver tolerance (1e-6 to 1e-3) across 16 deterministic runs starting at seed
20260510.

## Determinism

The sweep is bit-deterministic for fixed seed plus parameter tuple. Re-running
with `--seed 20260510 --iterations 16` reproduces the same per-iteration
SHA-256 across L1, L2, L3, and events.
