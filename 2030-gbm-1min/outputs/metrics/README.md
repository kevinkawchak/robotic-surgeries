# Per-Iteration Metric Outputs

Generated by `python -m metrics.compute_1min --iterations-dir
outputs/iterations --baseline data/human_surgeon_baseline.csv --out
outputs/metrics/robot_outcomes_1min.parquet --aggregate-iterations`. The
script reads the cross-iteration index.jsonl, computes per-iteration metric
rows under the frozen weighted formula, and appends the 30-row human surgeon
baseline (6 international centers).

## Composite Score Formula

```
composite = 0.40 * quality
          + 0.25 * (100 - 100 * total_seconds / 14400)
          + 0.20 * (100 - 100 * cost_usd / 50000)
          + 0.10 * safety
          + 0.05 * patient_experience
```

The structural caveat on the time dimension is documented in the comparison
prompt and report: the 1-minute robot trivially beats the 1-hour baseline on
total_seconds.
