# Consolidated Reports

Narrative reports that consolidate the artifacts produced by every step of
the pipeline. These reports are intended for paper publication and for
release-note drafting.

## Files

| Filename            | Purpose                                                      |
|---------------------|--------------------------------------------------------------|
| run_summary.md      | environment, pipeline order, headline outcomes, footprint    |
| process_log.md      | step-by-step narrative of the full run process               |
| final_report.md     | abstract, key findings, robot-vs-human table, conclusions    |
| limitations.md      | what was approximated or could not be run end to end         |
