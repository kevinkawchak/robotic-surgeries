# Vascular Safety Execution

This directory captures the live run output of the 5 vessel vascular safety zone gate at `../../codegen/src/vascular/safety_zone_gate.py`. The gate evaluates the tip position against 5 named vessel centerlines (superior mesenteric vein, portal vein, hepatic artery common, celiac axis, superior mesenteric artery) and returns one of 4 actions (clear, no_fly, soft_warning, hard_stop).

## Reproduction

```bash
cd 2030-pdac-1min/paper/codegen
PYTHONPATH=. python -c "
from src.vascular.safety_zone_gate import gate
print(gate((15.0, -45.0, -50.0), phase=2))
"
```

## Sample Tip Path Gate Verdicts (Phase 2, Approaching SMV)

A 100 tick sample path is generated by sweeping the tip x coordinate from 50 mm (far right) to 15 mm (SMV centerline) at fixed y = -45 mm and z = -50 mm in Phase 2 (vessel control). The gate produces:

| Action | Count |
|--------|-------|
| clear | 83 |
| no_fly | 6 |
| soft_warning | 6 |
| hard_stop | 5 |

The transition pattern (clear -> no_fly -> soft_warning -> hard_stop) demonstrates the defense in depth contract: as the tip approaches the SMV, the gate progressively reduces the velocity scale and the force soft cap, and finally e stops the per arm when the tip enters the 2 mm hard stop radius.

## Cross Iteration Safety Statistics

Across the 32 iteration deterministic sweep at `../iterations/index.jsonl`, zero safety zone violations occur. The 0 of 32 violation rate is consistent with the 4 action gate producing a hard_stop verdict the moment any tip enters the hard stop radius, which preempts any committed violation.
